# 部署说明

覆盖两种部署方式：**服务器（Docker + systemd）** 与 **本地 Windows 调试**。

---

## 一、服务器部署（推荐）

以 Debian/Ubuntu 为例，假设部署到 `/root/QQ_chatbot`。

### 1. 准备代码

```bash
cd /root
git clone https://github.com/Laia-0721/qq-chatbot-framework.git QQ_chatbot
```

### 2. 部署 NapCat（QQ 协议端）

```bash
cd /root/QQ_chatbot/napcat

# 配置文件必须带真实 QQ 号，否则 NapCat 会忽略它们
cd config
mv napcat_ACCOUNT.json          napcat_<你的QQ号>.json
mv napcat_protocol_ACCOUNT.json napcat_protocol_<你的QQ号>.json
mv onebot11_ACCOUNT.json        onebot11_<你的QQ号>.json
cd ..

# 编辑 onebot11_<你的QQ号>.json，设置 token（与机器人端一致）、确认 url 端口
vi config/onebot11_<你的QQ号>.json

# 强烈建议同时修改 webui.json 的 token（否则后台可被任意访问）
vi config/webui.json

docker compose up -d
docker compose logs -f
```

首次运行需要在日志中**扫码登录 QQ**。

> `docker-compose.yml` 中的路径是相对路径（`./config`）。**不要移动该文件**，
> 否则 NapCat 会挂载到空目录并重新生成默认配置。

### 3. 部署机器人

```bash
cd /root/QQ_chatbot/qqbot
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -e .

cp .env.example .env
vi .env          # 填写 ONEBOT_ACCESS_TOKEN / DEEPSEEK_APIKEY / QWEATHER_* / 群号
```

先手动试跑，确认无报错：

```bash
.venv/bin/python bot.py
```

按 `Ctrl+C` 停止后，配置为系统服务：

```bash
cp qqbot.service /etc/systemd/system/qqbot.service
# 若部署路径不是 /root/QQ_chatbot，请先修改 qqbot.service 里的 WorkingDirectory 与 ExecStart
vi /etc/systemd/system/qqbot.service

systemctl daemon-reload
systemctl enable --now qqbot
systemctl status qqbot
journalctl -u qqbot -f
```

### 4. 生成城市映射（可选，但推荐）

```bash
cd /root/QQ_chatbot/qqbot
# 下载 CSV 后放到该目录：
# https://github.com/qwd/LocationList/blob/master/China-City-List-latest.csv
.venv/bin/python generate_city_mapping.py
```

不生成则天气只能查内置的北京 / 上海 / 临沂。

## 二、本地 Windows 调试

```powershell
# 1) QQ 协议端（需要 Docker Desktop）
cd napcat
# 同样先把 config 下的文件名改成自己的 QQ 号
docker compose up -d
docker compose logs -f

# 2) 机器人
cd ..\qqbot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
copy .env.example .env
notepad .env
python bot.py
```

> 如果 NapCat 跑在另一台机器或另一个容器里，
> 请把 `onebot11_<QQ号>.json` 中的 `ws://127.0.0.1:8081/...` 改成机器人所在的可达地址。

---

## 三、更新

```bash
cd /root/QQ_chatbot
git pull
cd qqbot
.venv/bin/pip install -e .
systemctl restart qqbot
```

`data/` 下的运行时数据（打卡、昵称缓存）不在版本控制中，更新不会丢失。

---

## 四、安全清单

发布或部署前请逐项确认：

- [ ] `.env` 未被提交（已在 `.gitignore` 中排除）
- [ ] `napcat/config/onebot11_*.json` 中的 `token` 未被提交
- [ ] `napcat/config/webui.json` 的 `token` 已设置强口令（**不要留空**）
- [ ] `napcat/config/webui.json` 的 `accessControlMode` 已按需限制来源 IP
- [ ] `napcat/ntqq/` 未被提交（含登录态与聊天记录，已排除）
- [ ] `qqbot/data/signin.json`、`nickname_cache.json` 未被提交（含真实 QQ 号，已排除）
- [ ] 若服务器有公网 IP，WebUI（默认 `6099`）不对公网开放，建议仅监听 `127.0.0.1` 并走 SSH 隧道

> 默认配置下 WebUI 的 `token` 为空、监听所有网卡。**直接上线等于把 QQ 账号管理后台暴露给全网**，
> 请务必先修改。
